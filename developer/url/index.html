URL Encoder / Decoder

한글이나 특수문자가 들어간 값을 퍼센트 인코딩하고 인코딩된 URL을 읽을 수 있게 되돌립니다. URL을 넣으면 도메인, 경로, 쿼리 파라미터로 나눠 보여 줍니다.

브라우저에서만 처리 무료 · 회원가입 없음

구성 요소

쿼리 파라미터

사용 방법

  1. 쿼리스트링 값 하나를 넣을 때는 encodeURIComponent, URL 전체를 다룰 때는 encodeURI를 고릅니다.
  2. 값을 입력하고 인코딩 또는 디코딩을 누릅니다.
  3. URL 분석 탭에서는 URL을 프로토콜, 호스트, 포트, 경로, 해시와 쿼리 파라미터로 나눠 디코딩된 값으로 보여 줍니다.

URL 인코딩(퍼센트 인코딩)이란

URL에는 영문, 숫자, 일부 기호만 쓸 수 있습니다. 한글이나 공백, & ? 같은 예약 문자를 값으로 넣으려면 UTF-8 바이트를 %XX 형태로 바꿔야 합니다. 예를 들어 '한글'은 %ED%95%9C%EA%B8%80이 됩니다.

방식별 인코딩하지 않는 문자

  • encodeURIComponent: A-Z a-z 0-9 - _ . ! ~ * ' ( )
  • encodeURI: 위 문자에 더해 ; , / ? : @ & = + $ #

자주 묻는 질문

encodeURIComponent와 encodeURI는 무엇이 다른가요?

encodeURIComponent는 / ? & = # 같은 구분 문자까지 모두 인코딩해서 쿼리 값 하나를 넣을 때 씁니다. encodeURI는 URL 구조를 이루는 문자는 남기고 한글·공백 등만 인코딩해서 URL 전체를 다룰 때 씁니다.

공백을 + 로 바꾸고 싶어요.

'공백을 + 로' 옵션을 켜면 HTML 폼 전송(application/x-www-form-urlencoded) 방식처럼 공백이 + 로 인코딩됩니다. 디코딩할 때도 + 를 공백으로 바꿉니다.

잘못된 % 시퀀스가 있으면 어떻게 되나요?

%E3%8 처럼 깨진 시퀀스가 있으면 디코딩 오류와 함께 문제 위치를 알려 줍니다.
