Base64 Encoder / Decoder

텍스트나 파일을 Base64로 인코딩하고 Base64 문자열을 원래 텍스트로 되돌립니다.
한글은 UTF-8로 처리하고 URL-safe 형식도 지원합니다.

브라우저에서만 처리 무료 · 회원가입 없음
0자 · 0 B

사용 방법

  1. 텍스트 탭에서 내용을 입력하고 인코딩 또는 디코딩을 누릅니다. '입력하면서 변환'을 켜 두면 마지막으로 누른 방향으로 바로 바뀝니다.
  2. JWT나 URL 파라미터에 쓸 값이면 URL-safe를 켜세요.
  3. 파일 → Base64 탭에서는 이미지나 폰트를 Data URL로 바꿔 HTML·CSS에 바로 넣을 수 있습니다.

Base64란

Base64는 바이너리 데이터를 A–Z, a–z, 0–9, +, / 64개 문자로 표현하는 인코딩입니다. 3바이트를 4글자로 바꾸기 때문에 결과는 원본보다 약 33% 커집니다. 이메일 첨부, Data URL, HTTP Basic 인증 헤더, JWT 등에 쓰입니다.

Base64는 암호화가 아닙니다. 누구나 디코딩할 수 있으니 비밀번호나 개인정보를 숨기는 용도로 쓰면 안 됩니다.

자주 묻는 질문

한글이 깨지지 않나요?

텍스트를 UTF-8 바이트로 바꾼 뒤 인코딩하므로 한글과 이모지도 그대로 복원됩니다. btoa()를 바로 쓰면 생기는 오류가 없습니다.

URL-safe Base64는 무엇인가요?

URL에 넣을 때 문제가 되는 + 와 / 를 - 와 _ 로 바꾸고 끝의 = 패딩을 뺀 형식입니다. JWT도 이 형식을 씁니다. 디코딩할 때는 두 형식을 자동으로 인식합니다.

파일을 Base64로 바꿀 수 있나요?

네. 파일을 선택하면 Data URL(data:image/png;base64,...) 형식으로 바꿔 줍니다. 파일은 업로드되지 않고 브라우저에서 읽기만 합니다.
