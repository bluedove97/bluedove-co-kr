사용 방법

텍스트 비교 (Diff)

원본(A)과 변경본(B)을 넣고 비교하기를 누르면 추가된 줄은 초록색, 지워진 줄은 빨간색으로 표시합니다. 바뀐 줄 안에서 달라진 글자를 한 번 더 강조합니다. 코드 리뷰, 계약서 수정본 확인, 설정 파일 비교에 쓸 수 있습니다.

줄 정렬 · 정리

목록을 가나다순·숫자순·길이순으로 정렬하고 중복 줄과 빈 줄을 지웁니다. 이메일 목록 정리, 키워드 중복 제거, 로그 정리에 편합니다. 한글은 국어 사전 순서로 정렬합니다.

글자 수 세기

공백 포함·제외 글자 수와 단어 수, 줄 수, 바이트 수를 입력하는 대로 셉니다. 자기소개서 글자 수 제한이나 문자 메시지(SMS 90바이트, LMS 2,000바이트) 길이를 확인할 때 쓰세요. 이모지와 결합 문자는 눈에 보이는 한 글자를 1자로 셉니다.

자주 묻는 질문

어떤 알고리즘으로 비교하나요?

git diff 등에서 쓰는 Myers 차이 알고리즘으로 최소 편집 단위를 찾고 바뀐 줄 안에서는 글자 단위로 다시 비교해 달라진 부분을 강조합니다.

글자 수에서 바이트는 어떻게 계산하나요?

UTF-8 기준입니다. 영문·숫자는 1바이트, 한글은 3바이트, 이모지는 대부분 4바이트로 셉니다. EUC-KR(한글 2바이트) 기준 값도 함께 보여 줍니다.

비교할 텍스트가 저장되나요?

저장하지 않습니다. 페이지를 닫으면 사라지며 서버로도 전송되지 않습니다.
