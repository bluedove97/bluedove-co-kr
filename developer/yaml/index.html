JSON ↔ YAML 변환

JSON을 YAML로, YAML을 JSON으로 바꿉니다.
쿠버네티스 매니페스트나 docker-compose 파일, CI 설정, springboot의 설정을 옮길 때 편합니다.

브라우저에서만 처리 무료 · 회원가입 없음

사용 방법

  1. JSON을 YAML로 바꾸려면 왼쪽에 JSON을 넣고 JSON → YAML을 누릅니다.
  2. YAML을 JSON으로 바꾸려면 오른쪽에 YAML을 넣고 YAML → JSON을 누릅니다.
  3. 문법 오류가 있으면 줄과 칸 위치를 알려 줍니다.

JSON과 YAML, 언제 무엇을 쓸까

JSON은 기계가 주고받기 좋은 엄격한 형식이라 API 응답과 설정 파일에 널리 쓰입니다. YAML은 들여쓰기로 구조를 나타내고 주석을 달 수 있어서 사람이 직접 고치는 설정 파일에 많이 씁니다. 쿠버네티스 매니페스트, docker-compose, GitHub Actions, GitLab CI가 YAML을 씁니다.

변환할 때 알아 둘 점

  • YAML의 주석(#)은 JSON에 담을 수 없어서 변환하면 사라집니다.
  • yes, no, on, off는 YAML 1.2 기준으로 문자열로 처리합니다. 불리언이 필요하면 true/false를 쓰세요.
  • 0755처럼 앞에 0이 붙은 값이나 1.10 같은 버전 문자열은 따옴표로 감싸야 숫자로 바뀌지 않습니다.

자주 묻는 질문

여러 문서가 들어 있는 YAML(--- 구분)도 변환되나요?

네. 문서가 2개 이상이면 JSON 배열로 변환합니다. 반대로 JSON 배열을 YAML로 바꿀 때 '배열을 여러 문서로 나누기'를 켜면 --- 로 구분된 다중 문서가 됩니다.

YAML 앵커(&)와 별칭(*)도 지원하나요?

네. YAML을 읽을 때 앵커와 별칭을 풀어서 JSON 값으로 펼칩니다.

어떤 라이브러리를 사용하나요?

검증된 오픈소스 파서 js-yaml(MIT 라이선스)을 사이트에 직접 포함해서 사용합니다. 외부 CDN이나 서버를 거치지 않습니다.
